# Dungeons & Dragons Game

A turn-based, single-player role-playing game developed in **C++** that adheres to the **d20 gaming rules**. The game features exploration, combat, NPC interactions, and item management, designed for an engaging and interactive experience.

## Features

### 1. **Grid Map System**
- **Interactive Map**: Players can move across a grid map where cells can represent walls, rooms, doors, or chests.
- **Movement**: The player can navigate through the map, interacting with NPCs, doors, and other game elements.
- **NPCs**: Friendly and hostile NPCs (Non-Player Characters) populate the map, each with distinct behaviors like combat or interaction.
  - Hostile NPCs act as monsters, which can engage in combat with the player.
  - Friendly NPCs can be interacted with for quests, conversations, or assistance.
  
### 2. **Combat System**
- **Turn-Based Combat**: Players and NPCs take turns during combat, based on the **d20 rule system**.
- **Monsters and Combat**: Players can encounter hostile NPCs and engage in combat using various weapons and abilities.
- **Simplified NPC Actions**: NPC actions are simplified for easy interaction, either through combat or conversations.

### 3. **Item Management**
- **Item Inventory**: The game includes a robust item management system, where players can collect and equip items, such as:
  - **Armor**
  - **Shields**
  - **Weapons**
  - **Boots**
  - **Rings**
  - **Helmets**
  
- Players can pick up items, store them in their inventory, and equip them for combat advantages.

### 4. **Game Mode**
- **Single-Player Focus**: The game is designed for single-player mode, allowing players to explore the world, interact with NPCs, and engage in combat without the need for complex multiplayer or advanced AI interactions.
  
### 5. **Game Mechanics**
- **Turn-Based Exploration**: Players move across the map in turns and can interact with different elements like NPCs, doors, chests, and items.
- **Combat System**: Follows the d20 system, where players roll dice to determine the outcome of combat actions.
- **NPC Interactions**: Depending on the NPC type, players can have friendly interactions or engage in combat.
